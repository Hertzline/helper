Unknown tokens are rejected before any elevation prompt (exit code 2).

## Crash / uninstall restore story

1. Snapshots stay in user data owned by `core` (written before apply).
2. Restore must run without the UI for triggers: `crash`, `uninstall`, `watchdog`, `explicit`.
3. Unprivileged reverses run in-process; privileged leftovers call `hertzline-helper restore_all --reason <trigger>`.
4. Uninstall scripts (packaging) invoke restore before deleting binaries; Windows MSI/uninstall script, Linux prerm, macOS uninstall + `SMAppService.unregister()`.
5. Implementation of real restore is HZ-018; this spike locks the contract and headless requirement.

## Decision

**Chosen:**

- Windows: short-lived elevated `hertzline-helper` via `ShellExecuteEx` + `runas` (not a service).
- Linux: polkit policy `org.hertzline.helper.*` + `pkexec` of the helper with argv allow-list; draft policy in `policy/linux/`.
- macOS: `SMAppService.daemon` with register-on-first-need and unregister-on-uninstall; accept OS always-on-after-approval constraint with a minimal allow-list.
